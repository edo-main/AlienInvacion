# ALIEN INVACION

#### Космический шутер, созданный по мотивам книги **"Python Crash Course"** от автора *Эрика Мэтиза* с собственными улучшениями и доработками.

![Геймплей](screenshots/gameplay.gif)
___
## Управление

| Действие | Клавиша |  
| Движение влево | Стрелка влево |  
| Движение вправо | Стрелка вправо |  
| Стрельба | Пробел |  
| Продолжить игру / Пауза | Escape |    

## Особенности

**Удобное управление и меню** 

**Бонусы бафа характеристик**  

**Уникальная графика и зыуки** 

**Динамичный фон**

**Случайные движения инопланетян**

**Разные типы вражеских кораблей**


## Что реализовано
 - **Независимое перемещение врагов**
 - **Уничтожение врагов при попадании пуль**
 - **Уничтожение собственного корабля при контакте с вражескими**
 - **Старт игры по кнопке "NEW GAME"**
 - **Увеличение сложности**
 - **Уникальная графика и звуки**
 - **Вывод рекордного счёта и прочее**
